# 🧩 玩轉方塊 — 新手魔術方塊還原教學

一個活潑童趣的互動教學網站，用會旋轉的 3D 方塊，一步一步教你把魔術方塊**完整還原**。專為看不懂傳統圖解、無法對照自己方塊狀況的新手設計。

## ✨ 特色

- **可拖曳旋轉的互動 3D 方塊**，支援手機觸控
- **完整三層還原**：第一層 → 第二層 → 第三層，另附 **2×2** 迷你版
- **對照圖庫**：每個步驟都把各種情況畫成迷你 3D 圖卡，你看手上方塊像哪張就點哪張，方塊立刻擺成那樣讓你比對
- **慢動作分解**：先停在「還沒歸位」的樣子讓你看清楚，再按「🐢 慢慢轉」逐步示範，每一步都說明「為什麼這樣轉」
- **Lottie 動畫**點綴（火花、完成灑花）
- 單一 HTML 檔、函式庫內嵌，**離線也能開**

## 📚 教學內容

1. **分層還原的觀念** — 像蓋房子一樣一層一層往上疊
2. **轉法記號** — R / L / U / D / F / B ＋ 中層 M / S / E，附互動示範
3. **第一層（照 maru 的拼整面邏輯）**
   - 拼好白色面：白色邊塊 5 種情況、白色角塊 4 種情況
   - 對齊側邊：maru 原公式 `M S D S′ D² M′`（對調相鄰邊）、`L D R′ L′ D′ R L D L′`（對調相鄰角）
4. **第二層** — 中間層邊塊，往右插 / 往左插
5. **第三層** — 黃色十字（點 / 直角 / 橫線辨識）、翻黃角、喬角塊、喬邊塊
6. **2×2 延伸** — 8 角塊迷你方塊，同一套右手口訣
