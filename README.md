# 🧩 玩轉方塊 — 新手魔術方塊還原教學

一個活潑童趣的互動教學網站，用會旋轉的 3D 方塊，一步一步教你把魔術方塊還原。

## ✨ 特色
- 可拖曳旋轉的互動 **3D 方塊**（支援手機觸控）
- **第一層 → 第二層 → 第三層** 完整還原教學，外加 **2×2** 迷你版
- 每個情境都能 **慢動作分解示範**，逐步解說「為什麼這樣轉」
- 靜態「圖例」＋動態示範並存，搭配 Lottie 動畫點綴
- 單一 HTML 檔、函式庫內嵌，**離線也能開**

## 🚀 線上觀看（GitHub Pages）
啟用後網址會是：`https://<你的帳號>.github.io/<repo名>/`

### 三步驟啟用 GitHub Pages
1. 進入這個 repo 的 **Settings（設定）**
2. 左側選 **Pages**
3. Source 選 **Deploy from a branch** → Branch 選 **main**、資料夾選 **/(root)** → 按 **Save**

等一兩分鐘，重新整理 Pages 頁面就會看到你的網址。用手機瀏覽器打開即可，也可以「加入主畫面」像 App 一樣使用。
